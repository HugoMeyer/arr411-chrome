C411 -> qBittorrent (extension Chrome)

Installation :
1. Place ce dossier quelque part ou il restera (ne pas le supprimer ensuite).
2. Ouvre chrome://extensions et active le "Mode developpeur" (en haut a droite).
3. Clique "Charger l'extension non empaquetee" et choisis ce dossier (celui qui contient manifest.json).
4. Clic droit sur l'icone de l'extension > Options :
   - qBittorrent : URL de la WebUI, utilisateur, mot de passe, puis "Tester".
   - Radarr / Sonarr / Lidarr (facultatif) : URL + cle API (Parametres > General), puis "Tester".
   Chrome demandera l'autorisation d'acceder a tes serveurs : accepte.
5. Va sur C411 (F5 si la page etait deja ouverte) : un bouton "qBittorrent" apparait a cote de "Telecharger".

Badges de score : sur la page d'un torrent, dans la liste "Versions" et dans les resultats, une pastille de 0 a 100
note chaque version (langue, qualite, seeders, taille). Etoile = meilleur choix, balance = meilleur rapport
qualite/taille, losange = meilleure qualite, eclair = plus de seeders. Clique sur la pastille pour le detail.
Profil du score : dans Options > "Score des torrents", choisis ce qui compte le plus (Equilibre par defaut, Qualite d'image,
VF / MULTI d'abord, Petite taille, Ratio, ou Personnalise avec tes propres poids). Le changement s'applique en revenant sur l'onglet C411.
Bouton "Envoyer le meilleur" : sur la page d'un torrent, a cote de "qBittorrent", il envoie la version qui a l'etoile selon ton profil
(l'infobulle dit laquelle). Si c'est une autre version, sa page s'ouvre puis le dialogue d'envoi habituel : tu choisis la categorie et tu
confirmes ; rien n'est envoye sans cela.

Espace disque : le dialogue d'envoi affiche l'espace libre de la categorie choisie et previent, sans bloquer, si le torrent
ne tient pas (qBittorrent 5.3 ou plus recent ; avant, rien ne s'affiche).

Mise a jour : le popup de l'extension signale une nouvelle version (verification toutes les 12 h au plus, aucune donnee envoyee).
Pour mettre a jour : recupere le depot, puis clique sur le bouton de rechargement de l'extension dans chrome://extensions.

Radarr/Sonarr/Lidarr : les films/series/albums sont ajoutes NON surveilles, sans recherche automatique.
Lidarr : categorie qBittorrent "lidarr" par defaut. L'album est detecte grace a la fiche musique de C411
(MusicBrainz/Deezer/Discogs) ; artiste et album restent modifiables avant l'envoi.
